# TEKSUM image assets

Place customer-facing service images in `public/images/services/`:

- `data.webp` — data service visual
- `airtime.webp` — airtime service visual
- `education.webp` — education service visual
- `cable.webp` — cable TV service visual
- `electricity.webp` — electricity service visual
- `airtime-pin.webp` — recharge-card PIN visual
- `international-airtime.webp` — international airtime visual

Provider logos can be added later under `public/images/providers/` using these filenames:

- `mtn.png`
- `airtel.png`
- `glo.png`
- `9mobile.png`
- `waec.png`
- `neco.png`
- `nabteb.png`
- `jamb.png`
- `dstv.png`
- `gotv.png`
- `startimes.png`
- `showmax.png`

Missing images intentionally fall back to the service/provider icon, so adding the files later does not require another code change.
